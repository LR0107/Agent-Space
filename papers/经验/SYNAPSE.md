# SYNAPSE: Trajectory-as-Exemplar Prompting with Memory for Computer Control

**ICLR 2024**

传统的电脑自动化系统通常依赖：

- 模仿学习（Behavior Cloning, BC）
- 强化学习（Reinforcement Learning, RL）

这些方法需要大量人工操作数据进行训练。

近年来，研究人员发现：

**大语言模型（LLM）可以通过少量示例（few-shot demonstrations）学习如何完成任务。**

这种方法叫：

> **In-context Learning（ICL，上下文学习）**

也就是说，不需要重新训练模型，只需要给LLM几个成功案例，它就能学习任务规律。

模型可以根据示例推断下一步操作。

论文指出，已有计算机智能体已经证明ICL有效，但仍存在三个主要问题。

**问题1：电脑状态太复杂，占用大量上下文空间**

电脑环境产生的信息非常多：

这些信息可能包含几万个token。但是LLM上下文长度有限。

结果：

- 能放入的示例数量减少
- 模型容易被无关信息干扰

论文提出：原始电脑状态中存在大量任务无关信息，会影响LLM生成正确动作。

**问题2：以前的方法不能表达完整任务过程**

以前很多智能体采用：

**方法A：高层计划（plan）**

问题：计划太抽象。

模型不知道：

- 每一步具体怎么操作
- 操作之后状态如何变化

**方法B：多选题形式（MCQ）**

例如：

当前状态：网页显示三个按钮

模型选择答案。

问题：它只能看到当前一步。不能学习完整轨迹。

论文认为：高层计划和多选都无法表示完整trajectory，因此在长流程任务中容易产生错误累积。

**问题3：无法利用不同任务之间的相似性**

以前方法通常：人工指定。

但是现实中很多任务类似：

例如：

- 回复邮件
- 转发邮件

它们界面和操作逻辑高度相似。旧方法不能自动发现这种关系。

## 二、研究方法

**方法1：State Abstraction（状态抽象）**

不要直接把完整网页给LLM。先进行压缩。

优点：

1. 减少token数量
2. 可以放更多示例
3. 减少无关信息干扰

状态抽象可以把复杂状态转换为简洁观察，从而支持后续轨迹示例学习。

注：llm完成

**方法2：Trajectory-as-Exemplar Prompting（轨迹作为示例）**

以前：状态 → 动作 一步一步预测。

SYNAPSE：完整任务轨迹作为示例提供给LLM。

优势：

1.学习长期规划

理解：“完成这个任务通常需要经历什么流程”。

2.减少错误累积

**方法3：Exemplar Memory（示例记忆）**

这是SYNAPSE的“长期记忆”。

记忆模块保存：

- 任务信息embedding
- 对应状态抽象方法
- 成功轨迹

然后通过相似度搜索自动选择示例。

**记忆库没有设计在线动态更新机制**

---

### 工作流程

- **输入任务和电脑状态**  
  智能体接收用户任务以及当前网页/电脑状态。
- **状态抽象（State Abstraction）**  
  将复杂的原始状态进行筛选，提取与任务相关的信息，减少无关内容。
- **检索相似经验（Exemplar Memory）**  
  根据任务相似度Top-k，从记忆库中找到相关的成功任务轨迹作为参考。
- **轨迹示例提示（Trajectory-as-Exemplar）**  
  将完整的**成功**任务操作轨迹提供给LLM（直接加入上下文窗口），让模型根据历史经验预测下一步动作。
- **执行动作并循环**  
  LLM输出操作，智能体执行后获得新状态，重复上述过程直到任务完成。

## 三、实验设计

论文主要测试两个benchmark：

**实验1：MiniWoB++**

是计算机控制领域常用测试环境。使用它测试智能体完成任务的成功率。

模型：

- GPT-3.5-turbo

实验方式：

- 每个任务运行50次
- 使用成功率作为评价指标

动作包括：

- click
- type
- press
- mouse操作

**对比方法**

传统训练方法

- CC-Net
- Pix2Act

微调方法

- WebGUM
- WebN-T5

ICL方法

- RCI
- AdaPlanner

**实验结果**

| 方法      | 平均成功率     |
| ------- | --------- |
| SYNAPSE | **99.2%** |
| Pix2Act | 96.2%     |
| CC-Net  | 93.5%     |
| RCI     | 90.6%     |

**实验2：Mind2Web**

是真实网站环境。

测试模型能否迁移到：

- 新任务
- 新网站
- 新领域

逐步加入三个模块

直接生成动作

加入：

1. State abstraction

2. TaE prompting

3. Exemplar memory

观察性能变化。

**实验结果**

加入三个模块后：

GPT-3.5：

- 状态抽象：+32%
- TaE：+50%
- Memory：+56%

## 四、总结

### 创新点

SYNAPSE首次把“完整任务轨迹”作为LLM电脑控制的few-shot示例，并结合自动检索记忆，使LLM能够利用过去经验完成长流程任务。

### 不足

**依赖高质量示例**

SYNAPSE本质仍然是：从已有成功轨迹中学习。

**推理成本较高：**每一步都需要调用LLM

导致：

- 延迟高
- API成本高

**Memory不是持续学习，只是检索库**

虽然叫memory，但实际上：提前建立数据库，测试时检索

因此它缺少：长期成长能力
